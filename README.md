# Awaise Khan — Professional Portfolio Website

## Files
- `index.html` — website content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation and year
- `assets/profile.png` — supplied professional photo

## Publish with GitHub Pages
1. Create/sign in to GitHub.
2. Create a repository named `YOURUSERNAME.github.io`.
3. Upload all files and the `assets` folder.
4. In repository **Settings → Pages**, choose the `main` branch as the publishing source.
5. Open `https://YOURUSERNAME.github.io/`.

For a custom domain, configure it in GitHub Pages and then update DNS at your domain provider.

## Notes
This is a static website, so it can be hosted by GitHub Pages without separate hosting.
